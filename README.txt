OFERTAS DO JOABEL

Este projeto contém uma vitrine de ofertas, página de detalhes, painel administrativo, API FastAPI e banco MySQL.

Para iniciar localmente, configure o arquivo .env com base em .env.example e consulte README.md.

Antes de publicar na internet, siga DEPLOYMENT.md. Não publique o arquivo .env nem reutilize a senha do banco que já apareceu no histórico Git.
